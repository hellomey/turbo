# AGENTS.md: apps/mobile (Flutter, Android + iOS)

Owner: `flutter-ui`. Root rules apply; also read `/dart/AGENTS.md`.

- Composition root only: theme, routing, providers, start-up (offline DB, sync engine). Screens come from `hm_features`.
- **Never depend on `hm_desk`.** Desk-only code must not ship in the mobile build (blueprint §35).
- Install size ≤ 40 MB, cold start ≤ 2.5 s on a low-end Android phone, Lite Mode on ≤ 3 GB RAM (§24, §10.8).
- Nothing secret in the app. The app never unlocks a purchase on its own; entitlements come from the server (§17.4).
- Platform folders (`android/`, `ios/`) are generated by `flutter create`; edit them only for signing, permissions, integrity APIs.
