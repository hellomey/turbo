# Port map

> GENERATED by tools/gen-ports.mjs from packages/config/ports.json. Do not edit.

Every HeyMey service on the single VPS uses a port from one series that starts at **4567**.
Only Caddy listens on the public internet (80/443); every port below binds to `127.0.0.1` in production.
Staging runs the same services at **production port + 100**.

| Block | Range | Purpose |
|---|---|---|
| apps | 4567–4579 | Our own deployable applications |
| data | 4580–4589 | Stateful services. Never published to the internet. |
| ops | 4590–4599 | Monitoring and staff tools. Reachable only via ops.heymey.app (VPN / IP allowlist). |
